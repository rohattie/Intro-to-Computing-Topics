/ ABOUT THIS RESOURCE

Understand the systems behind our digital world.

MODULE 01 / COMPUTER FUNDAMENTALS

Foundations & Architecture of Computing

01

1.1 Data, Information, and Knowledge

These concepts represent different stages of understanding and processing information.

◈

Data

Raw, unorganized facts and figures without context.

Example: 40, 39, 42

▤

Information

Processed data that becomes meaningful and useful.

Example: Average temperature is 40°C.

✳

Knowledge

Understanding information and applying it to make decisions.

Example: Activate cooling because the room is overheating.

1.3 The Four Cognitive Categories of the Human Mind

01 — Data Processing / Sensing

Receives information through environmental senses.

02 — Memory / Retention

Stores experiences, facts, and information.

03 — Reasoning / Logic

Analyzes information and solves problems.

Generates new ideas and original concepts.

1.5 Paradigms and Forms of Computing

  • Parallel Computing: Multiple processors execute different parts of a problem simultaneously.
  • Distributed Computing: Independent computers communicate over a network to accomplish a common task.
  • Personal Computing: Computing performed using an individual computer.
  • Client-Server Computing: Clients request services from a central server.
  • Peer-to-Peer Computing: Computers communicate and share resources directly.
  • Cloud Computing: Accessing computing services and resources through the Internet.

KEY CONCEPT: Parallel computing focuses on simultaneous processing, while distributed computing focuses on cooperation between connected computers.

2.1 What is an Information System?

An Information System (IS) is an organized combination of hardware, software, data, people, and procedures that collects, processes, stores, and distributes information to support decision-making.

2.2 The Five Core Components of an Information System

▣

Hardware

Physical equipment such as computers, keyboards, monitors, and servers.

⌘

Software

Programs and applications that control computer operations.

▤

Data

Raw facts and records processed into meaningful information.

≡

Procedures

Rules and instructions for using and operating a system.

◎

People

Users, operators, programmers, and administrators.

2.3 Foundations of Databases

A database is an organized collection of related data that allows users to store, retrieve, manage, and update information efficiently.

Entities and Relationships

ConceptMeaningExample
Strong EntityCan exist independently in a database.Student
Weak EntityDepends on another entity for identification or existence.Dependent
AttributesProperties describing an entity.Student ID, Name, Email
RelationshipsAssociations between entities.Student enrolls in Course

Types of Relationships

RelationshipMeaningExample
One-to-One (1:1)One record relates to one other record.Person and Passport
One-to-Many (1:M)One record relates to multiple records.Teacher and Students
Many-to-Many (M:N)Multiple records relate to multiple records.Students and Courses

KEY CONCEPT: A many-to-many relationship is normally resolved using an associative or junction table.

3.3 Essential MySQL Code Snippets

01 / CREATE TABLE WITH KEYS
CREATE TABLE Students (
    StudentID INT PRIMARY KEY,
    FirstName VARCHAR(50) NOT NULL,
    GPA DECIMAL(3,2),
    MajorID INT,
    FOREIGN KEY (MajorID)
    REFERENCES Majors(MajorID)
);
02 / INSERT RECORDS
INSERT INTO Students
(StudentID, FirstName, GPA, MajorID)
VALUES (101, 'Alice', 3.85, 2);
03 / QUERY WITH CONDITIONS
SELECT FirstName, GPA
FROM Students
WHERE GPA >= 3.5
ORDER BY GPA DESC;
04 / AGGREGATION AND GROUPING
SELECT MajorID, AVG(GPA) AS AverageGPA
FROM Students
GROUP BY MajorID
HAVING COUNT(*) > 5;

MODULE 04 / COMPUTER HARDWARE

Hardware, Memory & System Storage

04

4.1 Von Neumann Architecture

The Von Neumann Architecture is a computer design model that uses a shared memory to store instructions and data. Its major components include the CPU, memory unit, and input/output system.

⌘

Control Unit (CU)

Directs and coordinates computer operations and instruction execution.

∑

Arithmetic Logic Unit

Performs mathematical calculations and logical operations.

⚡

Registers

Small, high-speed storage locations inside the CPU.

4.2 Fetch-Decode-Execute Cycle

01 — Fetch

The CPU retrieves an instruction from memory.

02 — Decode

The Control Unit interprets the instruction.

03 — Execute

The CPU performs the required operation.

4.3 Hierarchical Memory System

Memory TypeVolatilityCharacteristics
RegistersVolatileVery small and extremely fast CPU storage.
Cache MemoryVolatileStores frequently accessed data and instructions.
RAMVolatileTemporarily stores running programs and data.
ROMNon-volatileStores persistent firmware instructions.
HDDNon-volatileUses magnetic storage technology.
SSDNon-volatileUses flash memory for data storage.

4.4 Primary vs. Secondary Storage

Primary StorageSecondary Storage
Directly accessible by the CPU.Used for long-term storage.
Generally faster.Generally slower than primary memory.
RAM, ROM, Cache.HDD, SSD, USB Drive.

5.3 The OSI Reference Model

The Open Systems Interconnection model consists of seven layers that explain how data travels through a network.

LayerNameFunctionExamples
7ApplicationProvides network services to applications.HTTP, FTP, SMTP
6PresentationHandles data formatting, encryption, and compression.JPEG, Encryption

4TransportProvides end-to-end communication.TCP, UDP

1PhysicalTransmits raw bits through physical media.Cables, Hubs
